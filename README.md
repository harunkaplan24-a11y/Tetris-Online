# Tetris Online

Android için klasik Tetris oyunu.

## Özellikler
- Klasik Tetris taşları
- Dokunmatik kontroller
- Taş döndürme ve hızlı düşürme
- Satır temizleme
- Puan ve level sistemi
- Level yükseldikçe artan hız
- Online skor tablosu için altyapı

## Proje
İlk sürüm Android Studio + Kotlin ile geliştirilecektir. Online skor sistemi sonraki aşamada Firebase/Firestore ile eklenecektir.
