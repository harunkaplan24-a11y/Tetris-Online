# Güvenlik Kuralları

- Host kullanıcıya bağlantı isteğini açıkça göstermelidir.
- Varsayılan olarak uzaktan kontrol kapalı olmalıdır.
- Her bağlantı için kimlik doğrulama yapılmalıdır.
- Parolalar düz metin saklanmamalıdır.
- İletişim şifrelenmelidir.
- Kullanıcı istediği anda bağlantıyı kesebilmelidir.
- Kamera, mikrofon, klavye kaydı ve gizli ekran görüntüsü alma özellikleri bulunmamalıdır.
- Yetkisiz erişim veya işletim sistemi güvenlik mekanizmalarını atlatma uygulanmamalıdır.
